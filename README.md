📌 Descripción del proyecto

proyecto-comercio es una API sencilla que simula la lógica de un pequeño sistema de comercio.
Incluye estructuras básicas para manejar recursos como usuarios, clientes, productos, compras, etc.

Sirve como base para aprender y practicar conceptos de desarrollo backend antes de avanzar a proyectos más completos.

🛠️ Tecnologías utilizadas

- Python 3
- Flask
- Flask-RESTful
- SQLite
- SQLAlchemy
- PyJWT (para autenticación JWT)

🎯 Objetivo del proyecto

- Practicar operaciones CRUD
- Entender el funcionamiento interno de Flask
- Aprender a estructurar APIs correctamente
- Trabajar con bases de datos usando SQLAlchemy + SQLite
- Subir y versionar un proyecto en GitHub

⚙️ Configuración de variables de entorno

Este proyecto utiliza variables de entorno para proteger información sensible (puertos, claves, credenciales, etc.).
En el repositorio encontrarás un archivo .env-example. Este archivo sirve de plantilla. Antes de ejecutar el proyecto debes crear tu propio archivo .env
